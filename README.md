# JETANK

Software for the Waveshare JETANK tracked robot on an NVIDIA Jetson Orin Nano Developer Kit.
The robot gets brought up one stage at a time: motion control, camera, telemetry, arm and gripper,
teleoperation, pattern recognition, and then self-driving.

See [CLAUDE.md](CLAUDE.md) for architecture, coding style, testing and workflow conventions,
and [`docs/hardware/`](docs/hardware/) for the schematic and hardware notes.
